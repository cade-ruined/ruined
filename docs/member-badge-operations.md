# Member badge operations

Use **Experiences → open an event → Change badge credit** to identify the program activity an event counts toward. Review the actual program schedule and audience before saving. An event title, RSVP, invitation, email reminder, or Google Meet link never establishes attendance or earns a badge.

## Review the December TIME calls

For the six December 2026 TIME calls, confirm each record against the approved schedule, then enter these values. The names below identify the records to review; they are not automatic classification rules.

| Call to review | Badge credit | Stage or topic | Program month |
| --- | --- | --- | --- |
| Membership TIME SEE | Membership call | See | 2026-12 |
| Membership TIME FACE | Membership call | Face | 2026-12 |
| Membership TIME CUT | Membership call | Cut | 2026-12 |
| Membership TIME GROW | Membership call | Grow | 2026-12 |
| Circle TIME WHY | Circle call | Why | 2026-12 |
| Circle TIME BUILD | Circle call | Implementation, only after confirming BUILD is the scheduled implementation session | 2026-12 |

Membership credit requires the **Weekly call** type and no Circle audience. Circle credit requires the **Circle meeting** type and its correct Circle audience. Keep **No badge credit** until any unclear classification is resolved. Do not move an event to another audience to make its badge classification fit.

**Change badge credit** also works for completed and archived events. It records an operator audit without changing the event details, attendance, Calendar invitation, or email sequence. Cancelled events remain excluded, including events archived after cancellation.

## Record attendance after the call

Open the event’s **People** view and use the existing roster controls. For each member whose attendance is confirmed, choose **Attended** and save. Confirm a member’s place first if they are not on the confirmed roster. Registration can affect Calendar delivery; it is separate from the badge credit action.

Only the latest attendance mark counts. **Check in**, **Not marked**, **No-show**, and a registration or invitation alone do not qualify. Correct an inaccurate attendance record with the appropriate latest mark. Calls must have occurred and remain published, completed, or archived without cancellation before their attendance can earn credit.

## Verify the result

The member’s **Badges** page refreshes progress when opened or returned to. One confirmed Membership call earns **In the Room**. All four distinct Membership stages in the same program month earn **The Whole Month**. Confirmed Why and Implementation calls in the same Circle and program month earn **Full Circle**, with Circle membership checked at each call’s time. An explicitly classified physical event with confirmed attendance earns **In Real Life**.

If a badge remains locked, check the event’s badge credit, program month, lifecycle, actual timing, and the member’s latest attendance. Repeated attendance at the same stage does not replace a missing stage. A saved classification can prepare future calls, but it cannot award attendance before the call happens.
